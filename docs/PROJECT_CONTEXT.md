# Контекст проекта после Claude

Этот файл сохраняет рабочие решения из памяти Claude, относящиеся к этому
репозиторию. Последняя запись в той памяти сделана в сентябре 2026 года.
Расписание, цены, состав групп и состояние хостинга могли измениться: перед
публикацией сверяйте их с текущим сайтом и с пользователем. Источник правил для
агентов — `AGENTS.md`; этот файл хранит предметный контекст.

## Сайт и публикация

- По проверке от 1 сентября 2026 года `oneofstudio.ru` обслуживался Yandex
  Cloud Object Storage и CDN. Для обновления файлов нужно загрузить их в бакет
  и сбросить кэш CDN. Порядок действий — в `docs/UPDATE_SITE.md`.
- Netlify не обслуживал боевой домен при той проверке. reg.ru оставался
  регистратором домена, а DNS был делегирован Yandex Cloud. Не предлагайте
  загрузку в Netlify или изменение файлов на reg.ru как способ обновить сайт.
- При выборе нового хостинга учитывайте доступность сайта для аудитории в РФ.

## Журнал студии

- Журнал находится в `journal/` как PWA; инструкция — `docs/JOURNAL.md`.
  Старый артефакт Claude не является рабочей версией.
- При изменении `journal/index.html` обновляйте `VERSION` в `journal/sw.js`,
  чтобы установленные копии получили новую версию. Для локального журнала
  сохраняйте адрес `http://localhost:8123/journal/`: запасное хранение в
  браузере привязано к origin.
- При повторной публикации не перезаписывайте рабочий
  `journal/me/config.js` пустым файлом из репозитория. Подробности о
  синхронизации, учёте оплат и родительском кабинете — в `docs/JOURNAL.md`.
