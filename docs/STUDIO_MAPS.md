# Карты студии

Обновление 05.10.2026. Пользователь попросил адаптировать карту 2ГИС для сайта и добавить Истомина, 41.

В `index.html`, под адресами в контактах, добавлены две карты 2ГИС. На ширине от 1000 px они стоят рядом, ниже — одна под другой. Высота 400 px, ширина 100%, отложенная загрузка. Ссылки открытия карты и маршрута работают отдельно от iframe. Существующие ссылки Яндекс Карт сохранены.

- Комсомольская, 78: 48.472687, 135.060674 из кода пользователя; ссылка на организацию 70000001117606574. Этаж и офисы — из `PROJECT_CONTEXT.md`.
- Истомина, 41: 48.472993, 135.061051 — точка здания, выбранная поиском адреса в официальном конструкторе https://makemap.2gis.ru/. Подпись Choreo 9+, синий зал и вход студии «Я в танцах» — подтверждённые сведения из `PROJECT_CONTEXT.md`. Это точка здания, не новая карточка организации в справочнике.

Исходный DGWidgetLoader формирует iframe с автоматически открытой карточкой, обрезающейся на узком телефоне. Поэтому обе карты используют экспорт официального конструктора 2ГИС с собственными подписями и масштабом 17. Атрибуция 2ГИС сохранена. Ключ API не нужен. Цвета и типографика блока наследуют текущий сайт.

Публикация: заменить `index.html` и `style.css` в корне бакета oneofstudio.ru и очистить CDN для `/`, `/index.html`, `/style.css`. Метка стилей главной: `20261005-maps`. Файлы подготовлены локально; загрузка в Yandex Cloud в этой сессии не выполнялась.

Проверка: локальный сервер 127.0.0.1:8125, ширины 390/1440/2560 px. Обе карты загрузились с отметками, высота 400 px, горизонтального переполнения нет. После исправления мобильного обрезания выполнена повторная визуальная проверка. Снимки сохранены в outputs текущего чата.
